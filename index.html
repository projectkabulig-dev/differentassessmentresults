📘 Paano gamitin

  1. Pumili ng dashboard sa ibaba o gamitin ang search box.
  2. I-click ang card. Magbubukas ito sa bagong tab.
  3. Mag-filter gamit ang mga dropdown at tab para makita ang resulta ng division, district, at school.
  4. I-hover ang mga chart para makita ang eksaktong numero.
  5. Online dapat ang device para lumabas ang mga chart at font.
